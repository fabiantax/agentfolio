AgentFolio — architecture note

How AgentFolio answers: the Microsoft Agent Framework pipeline

Every answer is streamed by a MAF agent over Microsoft.Extensions.AI, grounded in documents extracted by a process-isolated sandbox, and carries citations resolved server-side. This page documents the real path with file:line anchors and measured numbers.

Yes — answering runs on Microsoft Agent Framework. The chat endpoint builds a MAF AIAgent via IChatClient.AsAIAgent(...) (Microsoft.Agents.AI 1.21.0), drives it with CreateSessionAsync / RunStreamingAsync, and streams its tokens to the browser as SSE. The underlying IChatClient is the canonical MAF wiring: OpenAIClient → GetChatClient(model).AsIChatClient() pointed at any OpenAI-compatible endpoint (live demo: llama-swap → nemotron-4b).
